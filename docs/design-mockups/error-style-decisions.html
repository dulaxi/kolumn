Error style — one voice everywhere

Proposal: make the toast treatment (Catalog A) the app-wide error grammar. Below, every error surface shown as it is today vs. toastified. Two fills of the same grammar are on offer — solid (the literal toast) and wash (same anatomy, palette wash fill) — because the honest answer is that the solid fill doesn't survive everywhere. Toggle the theme; note which options adapt.

THE GRAMMAR

One anatomy, three weights

Everything shares the toast DNA: mono 12px, 18px Phosphor icon, 10px radius, 1px border, dismiss × where dismissible. What changes is the fill — matched to how long the message sits on screen.

SURFACE 7

Full-page ErrorBoundary — keep as-is

The copper-circle + serif-heading + lime "Try again" layout is a page state, not a message — same family as the 404 and empty states. Squeezing it into a 420px mono strip would undersell a whole-section crash. Recommendation: leave it, but its icon circle and copy tone become the "page-scale" end of the same copper vocabulary.

So — is it a good idea?

Standardizing on the toast grammar: yes, genuinely. It's already Kolumn's most distinctive system voice (mono, ink border, Phosphor icon, palette fills), it's the error style users see most, and it kills the five-variant drift outright. Standardizing on the literal solid toast: no. Four reasons visible above:

  • Transience is load-bearing. The solid fill works because it leaves after 4 seconds. Persistent solid-copper blocks compete with CTAs (Surface 1B), invert field hierarchy (2B), and read as stuck toasts in chat (4B).
  • Contrast. #FAF8F6 on copper is ~3.3:1 — a defensible cheat for a 4s toast, below AA for text someone must read while fixing a form. The wash tier pairs copper-dark text on copper-wash instead.
  • Theming. The toast hardcodes its hexes and ink border (audit finding). Making it the universal style as-is would spread the app's only non-theming surface everywhere. The wash tier is token-native — flip the theme toggle above to see B options stay frozen while C options adapt.
  • You already own the wash tier. InlineNotice is the toast grammar in wash form — one caller today. This proposal is less "restyle the app" and more "promote InlineNotice, add a micro variant, retire four hand-rolled banners."

The palette extension you asked about falls out naturally: copper=error, honey=warn/offline, lime=success, mauve=archive — each in solid (transient) and wash (persistent) form, all from existing tokens. One grammar, three weights, five hues.
