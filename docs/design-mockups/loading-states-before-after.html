The chunk-loading fallback used bg-black/50 at z-50; the modal it resolves into uses dimmed ink rgba(27,27,24,0.45) at z-40. The backdrop visibly shifted tone when the chunk landed. Toggle dark mode — the difference is bigger there.

F7

Chat composer while streaming

ChatInput.jsx · ChatPage.jsx:58

While a reply streamed (glitching logo mark), the send button stayed fully live — a second send could fire mid-stream and desync the thread. Now a busy prop blocks sends at Enter + button. Typing stays enabled on purpose: drafting the next message mid-reply is normal in chat.
