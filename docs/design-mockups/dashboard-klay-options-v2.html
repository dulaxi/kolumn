My take

B. Same footprint as today, and the time hook makes him informative — morning grow, afternoon tap, evening idle, night sleep, driven by the getGreetingSlot() you already run for the words. C is the charmer if you want more personality — perched on the input, he points at the hero instead of competing with it — but it costs either a second mascot (keeping the Sparkle) or the greeting's mark (dropping it). D is a shrine, E is furniture.

Reply B / C (or B + C — greeting swap and perch, dropping the Sparkle entirely) / D / E / A to leave it.
