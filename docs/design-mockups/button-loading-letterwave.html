Letter-wave loading

The Claude Code terminal treatment: the label's letters stay put while a bright spot ~2 letters wide travels through the word, wraps, and repeats. Not a background sheen — each character animates individually with a staggered delay. Three tunings below; pick one and it becomes Button.jsx's loading treatment.

Brightness wave

Label dims to 40%; the wave lifts letters back to full strength as it passes. Closest to the terminal original — high contrast between resting and lit letters, unmistakably "working".

B

Lime color wave

Letters rest at 55% and the wave tints them lime as it passes — the working state carries the brand accent through the label. Loudest of the three; the lime reads differently per button variant.

Subtle wave
