Symmetric, but still by hand

OUTCOME 2026-07-16: none shipped — the Phosphor Sparkle stayed. Kept as a record of the explored direction.

One organic spoke — wobble, taper, near-straight axis, rough width — is drawn once, then stamped six times around the center. Every stroke carries the same hand-made irregularity, so the mark reads as drawn while being exactly symmetric. Orbit dashes get the same treatment, 180° apart. The wobble is baked into the path (deterministic), not a filter.

Ships as <RippleMark /> — a static inline-SVG React component with the generated paths frozen in (no runtime randomness).
