Button loading concepts

Five industry-standard patterns for a button's in-flight state, each rendered live in Kolumn's tokens across primary / accent / secondary variants. The current dots treatment is shown first as the baseline to beat. All concepts assume the button also disables + sets aria-busy.

2026-07-13 · rework of F2/F4 territory · pick one, it becomes Button.jsx's single loading treatment

Current (baseline): label + cycling text dots — Saving  ·  Quiet and text-native, but subtle to the point of being missable, and the dots reflow slightly as they cycle. This is what we're replacing.
1

Leading spinner + label

GitHub Primer · Shopify Polaris · Ant Design · Bootstrap

A small spinner slides in before the label; the label persists (optionally swapped to the -ing verb). The de-facto industry default — users read "spinner = working" instantly, and the label keeps telling them what is working.

Saving Activating Importing
ForUniversally understood · label context preserved · trivial to retrofit (spinner in Button.jsx's loading branch)
AgainstButton width shifts when the spinner appears (mitigable with a width lock) · spinners everywhere can feel busy
2

Spinner replaces label, width preserved

Stripe · Material Design 3 · Linear · Vercel

The label vanishes; a centered spinner takes over while the button holds its exact width (label rendered invisible underneath). The most minimal read — the button itself becomes the progress indicator. Stripe pairs it with a success check at the end.

Saving Activate Pro Import data
ForZero layout shift · cleanest look · natural home for a success-check morph later
AgainstLoses the verb — on long waits users forget what's running · two simultaneous loading buttons become indistinguishable
3

Bouncing dot trio replaces label

Facebook · Messenger · Slack (message send) · iOS keyboards

Three dots pulse in sequence where the label was, width preserved. Softer and more "conversational" than a spinner — it reads as typing/thinking rather than machinery turning, which suits chat-adjacent products.

Saving Activate Pro Import data
ForZero layout shift · gentle, matches Kolumn's restrained voice · visually distinct from the chat TypingIndicator but same family
AgainstAlso loses the verb · dot-trio already "means" AI-typing in this app — could blur the AI/non-AI boundary
4

Shimmer sweep across the label

ChatGPT · Claude.ai · Arc · AI-era products broadly

The label stays put; a soft sheen sweeps through the text. No added elements, no layout change at all — the label itself signals work. Kolumn already owns a shimmer vocabulary (ai-skeleton-block, ai-shimmer-reveal), so this rhymes with the existing system.

Saving Activating Importing
ForLiterally zero layout shift · keeps the verb · extends the brand's existing shimmer language
AgainstSubtlest of the five — low-vision users may miss it (needs the disabled-dim as backup) · shimmer currently means "AI at work" in this app
5

Progress fill behind the label

GitHub (merge box) · installers · upload UIs · KDE/GNOME

A translucent bar sweeps across the button behind the persistent label — indeterminate here (eases to ~90% and holds), determinate when real progress exists. The strongest "something is genuinely happening" signal of the five.

Saving Activating Importing
ForKeeps the verb · most informative feel · upgrades cleanly to real progress (e.g. the migration import)
AgainstFake-progress can read dishonest on unpredictable waits · most visually loud option · most implementation surface

Orthogonal add-on (works with any pick): a brief success morph — spinner/label → checkmark for ~800ms before reverting (Stripe-style). Decide separately.
